## 1. Brand Identity

### 1.1 Name
**Novora** — a coined, ownable name (pron. *no-VOR-ah*).
- **"Nova"** → a bright new star; newness, energy, a breakthrough launch.
- **"-ora"** → suggests *aura* and *era* — a new era of commerce.

It reads as a premium tech/SaaS brand (think Linear, Vercel, Ramp), **not** a
generic "dropshipping guru" brand. It's short, brandable, and trust-forward.

**Tagline (primary):** AI-built stores that actually sell.
**Tagline (hero):** Launch a store that actually sells — built by AI in 72 hours.
**One-liner:** Your idea → a revenue-ready online store in 72 hours.

### 1.2 Logo concept
- **Logomark:** a 4-point **spark / nova** rendered in the brand gradient. The
  sparkle instantly signals "AI" while the upward, radiant geometry signals
  growth and launch. Clean, geometric, and scalable to a 16px favicon.
- **Wordmark:** "Novora" set in **Space Grotesk** (600–700 weight), tight
  tracking (-0.02em) for a modern startup feel.
- **Lockups:** horizontal (mark + wordmark) for the nav/footer; standalone mark
  for the app icon, favicon, and social avatar.
- Files: `assets/logo.svg` (horizontal), `assets/favicon.svg` (app icon).

**Clear space & don'ts:** keep clear space ≈ the height of the mark on all sides.
Don't stretch, recolor outside the palette, add drop shadows to the wordmark, or
place the gradient mark on a busy photo without a container.

### 1.3 Color palette
A dark, premium "obsidian" base with an electric **indigo → cyan** gradient. Trust
+ tech, never neon-gaudy.

| Token | Hex | Use |
|---|---|---|
| Obsidian (bg) | `#0A0B0F` | Primary dark background |
| Panel | `#0C0D13` | Alternating section background |
| Surface | `#14151D` | Cards, surfaces |
| Surface 2 | `#191B26` | Raised / nested surfaces |
| Text | `#F4F6FB` | Primary text on dark |
| Text muted | `#9DA3B8` | Secondary text |
| **Brand Indigo** | **`#7C6CFF`** | Primary accent |
| **Brand Cyan** | **`#22D3EE`** | Secondary accent / glow |
| Indigo Light | `#9D7CFF` | Kickers, links |
| Success | `#34D399` | Checks, revenue, "yes" |
| Amber | `#FFB020` | Star ratings |
| Warm | `#FF8A5B` | Urgency / scarcity accents (sparingly) |

**Signature gradient:** `linear-gradient(120deg, #7C6CFF 0%, #6AA8FF 45%, #22D3EE 100%)`
Used on the logomark, primary buttons, headline highlights, stat numbers, and glows.

A **light theme** (`#F4F6FB` base, same accents) is included and toggleable for
strong-contrast / daytime browsing.

### 1.4 Typography
Modern SaaS pairing:
- **Display / headings:** **Space Grotesk** (500/600/700) — geometric, techy, premium.
- **Body / UI:** **Inter** (400/500/600/700) — the SaaS standard; clean and legible.
- **Fluid scale:** headings use `clamp()` so type scales smoothly from mobile to desktop.
- **Fallbacks:** robust `system-ui` stack so the site still looks great if web fonts are blocked.

## 5. Conversion Strategy

The page is engineered around five psychological levers, all pointing at one CTA:

1. **Speed** — "72 hours", "48–72h turnaround", "live this week" repeated throughout.
   Fast outcome lowers perceived effort and risk.
2. **Simplicity (done-for-you)** — "no tech skills", "100% done-for-you", a 3-step
   process (Idea → Store → Sales). Removes overwhelm, the #1 pain point.
3. **Authority (AI-powered system)** — AI framed as a *system* that analyzes 12,400+
   winning stores; "engineered to convert," not guesswork. Justifies premium price.
4. **Scarcity** — "limited client spots each month," a live spots counter, and a
   founding-client launch offer. Creates urgency without feeling scammy.
5. **Outcome-based messaging** — every benefit is framed around *making money*
   ("a store that sells," "$9.2k first month," revenue counters), not just "building
   a store."

### 5.1 Page flow (logical path to action)
Hero (promise) → Trust bar → **Problem** (agitate pain) → **Benefits** (the fix) →
**How it works** (de-risk: it's easy) → **The Offer** (what you get) →
**Comparison** (why we're better) → **Services** (more value) → **Stats** (proof) →
**Pricing** (decision) → **Testimonials** (social proof) → **Guarantees** (remove risk) →
**Urgency + CTA** (act now) → **FAQ** (handle objections) → Footer (final CTA).

### 5.2 CTA system
- One primary action repeated everywhere: **"Get Your Store."**
- Secondary, lower-commitment option: **"Book a free strategy call."**
- Buttons use magnetic hover, gradient glow, and arrow motion to draw the eye.
- A sticky navbar keeps the primary CTA in reach at all times.

### 5.3 Trust & credibility (anti-"scammy dropshipping")
Flat transparent pricing, an explicit launch guarantee, "you own 100% of your store,"
real-human support, a results disclaimer on testimonials, and a restrained,
premium visual language — all positioning Novora as a credible agency, not a hype play.
